# Product Vision

Build a complete e-commerce webshop.

The webshop should eventually support:

## Customer

- homepage
- product listing
- categories
- product detail
- search
- filtering
- cart
- checkout
- registration
- login
- customer profile
- order history
- order details

## Products

- products
- categories
- variants
- prices
- inventory
- product images

## Orders

- order creation
- order items
- order status
- payment status
- customer information
- order history

## Payments

- Stripe
- payment creation
- payment confirmation
- webhook handling
- failed payments
- refunds where appropriate

## Administration

- product management
- category management
- inventory management
- order management
- customer management

## Marketing

- coupons
- discounts
- promotions

## Other

- email notifications
- validation
- authorization
- security
- tests
- logging
- error handling
- documentation

This list is not exhaustive.

The agent should discover additional missing functionality during development.
